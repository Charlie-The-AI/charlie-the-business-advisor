# Grounding Verification & Hallucination Defense

One of the greatest dangers of using raw LLMs in business applications is **hallucination**—when an AI confidently invents financial statistics, non-existent sales trends, or incorrect totals.

Charlie solves this through automated **Grounding Verification**.

Package: `@charlie-the-ai/advisor-ai`

---

## 1. How Grounding Verification Works

```text
  [ Raw Business Orders ]
            │
            ▼
  ┌────────────────────────────────────────────────────────┐
  │  Deterministic Analytics Engine                        │
  │  Calculates exact net revenue, Pareto Gini, RFM, AOV   │
  └────────────────────────┬───────────────────────────────┘
                           │ (Mathematical Snapshot)
                           ▼
  ┌────────────────────────────────────────────────────────┐
  │  Multi-Provider AI (OpenAI / Gemini / Claude)         │
  │  Interprets snapshot and suggests strategic actions   │
  └────────────────────────┬───────────────────────────────┘
                           │ (Proposed Recommendations + Evidence)
                           ▼
  ┌────────────────────────────────────────────────────────┐
  │  Grounding Verification Engine                         │
  │  Cross-checks every numerical claim against Snapshot   │
  └────────────────────────┬───────────────────────────────┘
                           │
       ┌───────────────────┴───────────────────┐
       ▼                                       ▼
  [ All Numbers Match ]               [ Number Mismatch / Hallucination ]
  Status: "verified" ✅                Status: "flagged" ⚠️
  Included in Advice                  Warning attached to limitations
```

---

## 2. Recommendation Grounding Statuses

Each recommendation generated by Charlie includes a `groundingStatus`:

| Status | Meaning | Action Taken by Charlie |
|---|---|---|
| `verified` | Every cited metric (e.g. `netRevenue: ₦250,000.00`, `totalOrders: 12`) matches the deterministic snapshot within mathematical tolerance. | Trusted and highlighted with a verified data badge. |
| `flagged` | The AI cited a number that contradicts the calculated snapshot (e.g. claimed revenue of `₦900,000` when the snapshot was `₦250,000`). | Marked as `flagged` with a diagnostic explanation added to `limitations`. |
| `unverified` | The recommendation made qualitative points without citing specific numerical evidence. | Displayed without a mathematical badge. |

---

## 3. Grounding Verification in Chat

When asking questions via `charlie.chat({ question, analytics })`:
- Charlie parses all numbers and metric assertions in the AI's reply.
- Returns an `evidence` array where each cited metric has `isVerified: true | false`.
- If an unverified claim is detected, an explanation is added to `chatResult.limitations`.
